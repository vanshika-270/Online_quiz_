ONLINE QUIZ SYSTEM - XAMPP
================================

1. Copy the online_quiz_project folder to:
   C:\xampp\htdocs\online_quiz

2. Open XAMPP and start Apache + MySQL.

3. Open phpMyAdmin:
   http://localhost/phpmyadmin

4. Import schema.sql.

5. Open:
   http://localhost/online_quiz/
